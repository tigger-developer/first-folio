#+TITLE: D078 - Source frontmatter loses to shared local YAML
#+SCHEMA: 1
#+STARTUP: overview
#+OPTIONS: toc:2 num:nil

* Report
:PROPERTIES:
:CUSTOM_ID: report
:END:

- Reported by :: Operator on 2026-11-07.
- User outcome :: A document cannot reliably override shared project YAML through its more specific source-document configuration.
- Emergency authority :: The operator invoked =BYPASS-GATE-7= on 2026-11-07 and required Markdown YAML and dotted Org source configuration to follow one precedence rule across downstream output consumers.

* Observed Behaviour
:PROPERTIES:
:CUSTOM_ID: observed-behaviour
:END:

- =aisle-seats.org= set =#+FOLIO.TITLE-PAGE.TITLE.POSITION:= first to =15%= and then to =40%=, while the nearest =script.yaml= set =folio.title-page.title.position: 10%=.
- Two temporary snapshots converted with the installed D077 candidate produced identical page-one bounds in both source cases: title =y=143.739pt= and subtitle =y=222.631pt=.
- Changing only the temporary local YAML from =10%= to =40%= moved the title to =y=370.794pt= and subtitle to =y=449.686pt=.
- Repository inspection confirms that the shared loader merges the source layer before the nearest local YAML layer, so the local value wins. This matches the current configuration documentation.

* Expected Behaviour
:PROPERTIES:
:CUSTOM_ID: expected-behaviour
:END:

- Operator requirement :: Supported document-specific =FOLIO= and =RENDER= source configuration overrides shared local YAML defaults. Explicit CLI overrides remain highest priority.
- Scope expansion :: The earlier script-only proposal is superseded by the operator's same-session instruction that Markdown YAML and dotted Org frontmatter behave consistently across downstream output consumers. Markdown manuscript source configuration follows the same shared-layer ordering.
- Format boundary :: The rule applies wherever the mode already supports source-document configuration: Org and Markdown scripts, and Markdown manuscripts. It does not introduce a new syntax for Fountain scripts, Org manuscripts or letters.
- Compatibility note :: This reverses the previously documented manuscript source-versus-local ordering and may alter documents that relied on local YAML overriding a source value.

* Reproduction
:PROPERTIES:
:CUSTOM_ID: reproduction
:END:

1. Place =folio.title-page.title.position: 10%= in the nearest =script.yaml=.
2. Place =#+FOLIO.TITLE-PAGE.TITLE.POSITION: 15%= in an Org script with a dedicated title page.
3. Convert to PDF and record the title bounds.
4. Change only the Org value to =40%= and convert again.
5. Observe identical bounds. Change the local YAML value to =40%= and observe that both title and subtitle move.

* Impact and Workaround
:PROPERTIES:
:CUSTOM_ID: impact-and-workaround
:END:

- Impact :: Per-document script cover and layout settings cannot take effect when the shared local YAML defines the same field. This defeats the portability and specificity expected from dotted Org configuration.
- Workaround :: Remove the overlapping key from local =script.yaml=, or change the local YAML value for every document sharing that configuration.
