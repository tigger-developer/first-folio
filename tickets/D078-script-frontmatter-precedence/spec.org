* Synopsis
:PROPERTIES:
:CUSTOM_ID: summary
:END:

- Outcome :: Supported source-document configuration overrides shared local YAML, while explicit CLI overrides remain highest.
- Source forms :: Markdown YAML =folio:= and =render:= mappings, and dotted Org =#+FOLIO...:= and =#+RENDER...:= fields.
- Consumers :: One resolved configuration is supplied to every applicable output route for the selected mode, including PDF, Typst, DOCX, ODT and semantic text conversion.
- Emergency authority :: The operator invoked =BYPASS-GATE-7= after an Org script's title position was ignored and required consistent Markdown and Org precedence across the application.

* Context
:PROPERTIES:
:CUSTOM_ID: context
:END:

** Problem
- The shared loader merged source configuration before local YAML. A shared project's =script.yaml= therefore overrode a more specific value embedded in the document.
- Script conversion extracted dotted Org configuration but did not extract equivalent Markdown YAML configuration.

** Scope
*** In scope
- One shared precedence order for script and manuscript modes that already support source-document configuration.
- Dotted Org and Markdown YAML configuration extraction for scripts.
- Existing Markdown YAML source configuration for manuscripts.
- CLI precedence, effective-value validation and atomic failure.
*** Out of scope
- A new source-configuration syntax for Fountain scripts, Org manuscripts or letters.
- New configuration keys, new output-specific cascades, metadata precedence, renderer layout changes or installed-binary replacement.

** AC078.1 - Source configuration overrides local YAML :ac:
:PROPERTIES:
:CUSTOM_ID: ac-078-1
:END:

- Criterion :: When the same property occurs in supported source-document configuration and the selected local base or style-specific YAML, the source value wins. Non-overlapping properties continue to merge recursively.
- Modes :: This applies to Org and Markdown scripts and to Markdown manuscripts. The resolved result is not changed by selecting PDF, Typst, DOCX, ODT or a semantic text target.
- Proven by :: [[#rt-078-1][RT078.1 - Supported source configuration follows one cascade]], [[#at-078-1][AT078.1 - Public commands honour source-over-local precedence]] and [[#ot-078-1][OT078.1 - Aisle Seats uses its Org title position]].

** AC078.2 - Explicit CLI overrides remain highest :ac:
:PROPERTIES:
:CUSTOM_ID: ac-078-2
:END:

- Criterion :: An applicable explicit CLI value overrides the same source-document property. Style selection follows the same ordering.
- Proven by :: [[#rt-078-1][RT078.1 - Supported source configuration follows one cascade]] and [[#at-078-1][AT078.1 - Public commands honour source-over-local precedence]].

** AC078.3 - Markdown and Org configuration are consumed, not rendered :ac:
:PROPERTIES:
:CUSTOM_ID: ac-078-3
:END:

- Criterion :: Script conversion projects supported Markdown YAML or dotted Org fields into the source layer before parsing. Those configuration declarations do not appear as script body content.
- Boundary :: Markdown =folio= and =render= namespaces must be mappings; missing delimiters and source configuration beyond the bounded prefix fail explicitly.
- Proven by :: [[#rt-078-1][RT078.1 - Supported source configuration follows one cascade]] and [[#at-078-1][AT078.1 - Public commands honour source-over-local precedence]].

** AC078.4 - Invalid winning source values fail atomically :ac:
:PROPERTIES:
:CUSTOM_ID: ac-078-4
:END:

- Criterion :: Effective-value validation occurs after merging. A lower local value cannot repair an invalid winning source value, and no target is published on failure.

* Solution Design
:PROPERTIES:
:CUSTOM_ID: solution-design
:END:

** Architecture context
- Shared ownership :: =internal/config= owns layer selection, recursive merging, style selection and effective-value validation for every mode.
- Script orchestration :: =internal/app= extracts source configuration before loading the effective configuration and passes one result to every target branch.
- Manuscript orchestration :: =internal/manuscript= retains its existing first-Markdown-input extraction and passes the same source layer to the shared loader.

** High-level design
- The low-to-high order is built-in base, built-in style, global base, global style, local base, local style, source document and CLI.
- Style selection inspects those same layers in the same order, preventing the chosen preset and merged values from disagreeing about precedence.
- Script Markdown extraction reads at most a 1 MiB prefix, recognizes an opening and closing YAML delimiter, decodes only =folio= and =render= mappings into the source layer, and leaves ordinary metadata to the script parser.
- Existing dotted Org extraction continues to validate recognized paths and report unknown =FOLIO= or =RENDER= fields through its warning channel.

** Format consistency
- Target selection occurs only after source extraction and shared configuration loading. PDF, Typst, DOCX, ODT and semantic text targets therefore receive the same effective configuration object.
- Consistency describes precedence for applicable fields. It does not make a renderer implement a setting outside that renderer's documented support contract.
- Modes without an existing source-configuration contract do not infer one from this precedence change.

** Validation, security and reliability
- Markdown namespaces are mapping-only. Missing closing delimiters, malformed YAML and configuration prefixes beyond 1 MiB fail before target creation.
- Effective-value validation runs after the final CLI layer. Invalid winning source values fail atomically; explicit CLI values can override them where the CLI defines that field.
- No new subprocess, network, cache, installation or publication behaviour is introduced. Source files and local YAML remain read-only.

** Verification mapping
- Shared order, both script source forms, manuscript precedence, CLI precedence, parsing bounds and atomic failure are covered by [[#rt-078-1][RT078.1 - Supported source configuration follows one cascade]].
- Built-executable public behaviour is covered by [[#at-078-1][AT078.1 - Public commands honour source-over-local precedence]].
- The reported composition is covered by [[#ot-078-1][OT078.1 - Aisle Seats uses its Org title position]].
- Reader-level composition remains [[#ut-078-1][UT078.1 - Source-driven placement is visually acceptable]].
