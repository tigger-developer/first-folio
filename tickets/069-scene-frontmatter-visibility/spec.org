* Synopsis
:PROPERTIES:
:CUSTOM_ID: summary
:END:

** Outcome
- Scene-level introductory paragraphs obey =render.frontmatter= in PDF, DOCX and ODT without being discarded by semantic text conversion.
** Before
- Plain paragraphs directly beneath an Org or Markdown scene heading were classified as dialogue, so =render.frontmatter: false= left them visible in rendered documents.
** After
- Those paragraphs are scene-frontmatter events. Rendered documents omit them when frontmatter is disabled; Markdown and Fountain conversions retain them.
** Unchanged
- Scene headings, stage directions, speaker cues and dialogue retain their existing visibility and semantics.

* Context

- Authority :: =BYPASS-GATE-7= was invoked on 2026-10-24 for the reported scene-paragraph visibility defect.
- Scope :: Org and Markdown stage-play parsing plus PDF, DOCX, ODT, Markdown and Fountain conversion behaviour.
- Boundary :: A scene introductory paragraph is plain text whose nearest structural heading remains the scene heading. Entering a nested direction, cue, prop, transition or another structural heading ends that direct scene-introduction context.
- Exclusions :: Fountain-input action classification, manuscript frontmatter, letter content and general dialogue inference.

* Solution Design

** Semantic event
- Add a scene-introduction event distinct from dialogue and global introductory text. Org tracks the current heading level; Markdown tracks the scene context until a nested dramatic construct begins.

** Output policy
- PDF and office renderers map the event to the existing frontmatter-paragraph role. Render filtering applies =render.frontmatter= to this event only for PDF, DOCX and ODT targets.
- Org, Markdown and Fountain emitters preserve the event as source content. Existing global introductory-material behaviour remains unchanged.

** Security and operational impact
- No new dependency, subprocess, input size, persistence or access boundary is introduced. Existing parsing and output bounds remain authoritative.
