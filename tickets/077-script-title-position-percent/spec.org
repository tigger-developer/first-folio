* Synopsis
:PROPERTIES:
:CUSTOM_ID: summary
:END:

- Outcome :: A percentage supplied as =folio.title-page.title.position= is used as that *literal percentage* rather than silently mapped to another position.
- Before :: Every non-=third= value became =40%= on ordinary or overlay title pages, while every non-=center= value became one-third inside dodge regions.
- Scope :: Script PDF title pages configured through the normal YAML cascade, including dotted Org frontmatter.
- Unchanged :: The named =third= and =center= compatibility values retain their established behaviour; compact title pages continue to ignore dedicated-page positioning.
- Emergency authority :: The operator invoked =BYPASS-GATE-7= after =#+FOLIO.TITLE-PAGE.TITLE.POSITION: 20%= in =aisle-seats.org= rendered at the fallback position.

* Context
:PROPERTIES:
:CUSTOM_ID: context
:END:

** Problem
- Script title-position percentages are parsed through the configuration cascade but are not represented faithfully by the renderer.

** Scope
*** In scope
- Literal percentages from =0%= through =100%= for ordinary, overlay-cover and dodge-cover script PDF title pages.
- Full-field validation errors and atomic non-publication for unsupported values.
- YAML and dotted Org source configuration through the existing cascade.
*** Out of scope
- Length units, manuscript chapter positioning, office output, compact script titles, cover background treatments, and changes to the named aliases.

- Proven by :: [[#rt-077-1][RT077.1 - Script title percentages control rendered PDF geometry]], [[#ot-077-1][OT077.1 - Aisle Seats uses its effective cascaded percentage]] and [[#ut-077-1][UT077.1 - Percentage placement is visually acceptable]].

* Solution Design
:PROPERTIES:
:CUSTOM_ID: solution-design
:END:

** Architecture context
- Configuration ownership :: =internal/config= continues to select the effective value through the existing cascade. D077 does not change layer precedence.
- Renderer ownership :: =internal/app/script_render.go= owns validated script title-position projection into the file-backed Typst template.
- Template ownership :: =templates/script.typ= continues to compose ordinary, overlay and dodge title pages from typed template data; it receives no unvalidated source literal.

** High-level design
- A single =scriptTitlePosition= resolver trims and normalizes the effective string before any title-page template data is published.
- =third= produces the established =30%= ordinary/overlay offset and one-third dodge factor.
- =center= preserves the established =40%= ordinary/overlay offset and one-half dodge factor.
- A finite numeric percentage from =0%= through =100%= produces the same normalized percentage for ordinary/overlay output and its exact value divided by 100 for dodge multiplication.
- Every other value returns an error naming =folio.title-page.title.position= before template execution or target publication.

** Placement semantics
- Ordinary and overlay title pages apply the literal percentage as preceding vertical space within the dedicated title content region.
- Dodge applies the literal percentage within each unchanged movable region bounded by the actual inset image. Existing clearance clamping still runs afterwards and does not reinterpret the requested position.
- Title and subtitle remain one measured group. A grouped author follows the existing layout contract; the optional bottom-centre author remains in the anchored metadata row from W073.

** Decisions and boundaries
- Compatibility :: Keep both named aliases unchanged rather than redefining =center= for ordinary/overlay pages.
- Validation :: Reject lengths and unknown words instead of retaining the former silent fallback.
- Cascade :: Preserve the existing effective-value precedence. The separately registered [[file:../D078-script-frontmatter-precedence/defect.org][D078]] owns the operator-requested script frontmatter precedence change.
- Formats :: PDF title-page projection is the only changed consumer. DOCX, ODT, manuscripts, letters and compact script title blocks remain unchanged.

** Security and reliability
- Input boundary :: The resolver accepts only two named values or a finite bounded number with a percent suffix; formatted output cannot inject Typst syntax.
- State and publication :: No new file, process, network, cache or concurrency behaviour is introduced. Invalid input exits before publication; existing atomic PDF output remains authoritative.
- Dependencies :: No dependency or generated asset is added.

** Verification mapping
- Literal overlay and dodge geometry, grouped subtitle movement and invalid-value publication are covered by [[#rt-077-1][RT077.1 - Script title percentages control rendered PDF geometry]].
- The reported document composition and current cascade boundary are covered by [[#ot-077-1][OT077.1 - Aisle Seats uses its effective cascaded percentage]].
- Reader-level composition remains [[#ut-077-1][UT077.1 - Percentage placement is visually acceptable]].
