* Synopsis
:PROPERTIES:
:CUSTOM_ID: summary
:END:

- Outcome :: A percentage supplied as =folio.title-page.title.position= is used as that *literal percentage* rather than silently mapped to another position.
- Before :: Every non-=third= value became =40%= on ordinary or overlay title pages, while every non-=center= value became one-third inside dodge regions.
- Scope :: Script PDF title pages configured through the normal YAML cascade, including dotted Org frontmatter.
- Unchanged :: The named =third= and =center= compatibility values retain their established behaviour; compact title pages continue to ignore dedicated-page positioning.
- Emergency authority :: The operator invoked =BYPASS-GATE-7= after =#+FOLIO.TITLE-PAGE.TITLE.POSITION: 20%= in =aisle-seats.org= rendered at the fallback position.

* Context
:PROPERTIES:
:CUSTOM_ID: context
:END:

** Problem
- Script title-position percentages are parsed through the configuration cascade but are not represented faithfully by the renderer.

** Scope
*** In scope
- Literal percentages from =0%= through =100%= for ordinary, overlay-cover and dodge-cover script PDF title pages.
- Full-field validation errors and atomic non-publication for unsupported values.
- YAML and dotted Org source configuration through the existing cascade.
*** Out of scope
- Length units, manuscript chapter positioning, office output, compact script titles, cover background treatments, and changes to the named aliases.

* Acceptance Criteria
:PROPERTIES:
:CUSTOM_ID: acceptance-criteria
:END:

** AC077.1 - A percentage remains the specified percentage :ac:
:PROPERTIES:
:CUSTOM_ID: ac-077-1
:END:

- Criterion :: Given =folio.title-page.title.position: N%= where =N= is from =0= through =100=, script PDF conversion uses exactly =N%= of the applicable title-placement region. Ordinary and overlay pages use the dedicated title content region; dodge uses each movable region bounded by the image.
- Cascade :: The behaviour is identical whether the winning value comes from YAML or dotted Org frontmatter.
- Proven by :: [[#rt-077-1][RT077.1 - Script title percentages control rendered PDF geometry]], [[#ot-077-1][OT077.1 - Aisle Seats uses its effective cascaded percentage]] and [[#ut-077-1][UT077.1 - Percentage placement is visually acceptable]].

** AC077.2 - Unsupported positions fail instead of falling back :ac:
:PROPERTIES:
:CUSTOM_ID: ac-077-2
:END:

- Criterion :: The named =third= and =center= values retain their existing meanings. A length, unknown token, negative percentage or percentage above =100%= reports =folio.title-page.title.position= and publishes no target.
- Proven by :: [[#rt-077-1][RT077.1 - Script title percentages control rendered PDF geometry]].

** RT077.1 - Script title percentages control rendered PDF geometry :testdef:
:PROPERTIES:
:CUSTOM_ID: rt-077-1
:END:

- Covers :: [[#ac-077-1][AC077.1 - A percentage remains the specified percentage]] and [[#ac-077-2][AC077.2 - Unsupported positions fail instead of falling back]].
- Boundary :: Public script PDF conversion with real Typst compilation and dotted Org configuration.
- Setup :: Equivalent Org scripts place a marker title at =20%= and =40%= with a background overlay and an inset dodge cover. Invalid cases use an unknown token, a length, =-1%= and =101%=.
- Action :: Convert every fixture and extract the marker's PDF bounds.
- Expected :: The =20%= marker is materially above the =40%= marker in both layout branches. Invalid values name the complete field and leave no target.
- Retention :: Persistent regression suite under =make test=.
