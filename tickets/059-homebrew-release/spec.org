* Solution design
Build the test helper before changing HOME. Keep the existing exporters intact.
Use Make's version components with POSIX expr instead of awk; parameterize only
the tap checkout. Retain the existing Go downloader, checksum and formula publisher.
Its local formula update occurs after tagging and is committed separately.

Security boundaries are unchanged: source checksums remain verified by Homebrew,
Git uses existing access, and the bounded live operation publishes only the
release and its formula. Local fixtures never contact GitHub. The isolated tap
clone avoids staging another checkout's edits. A failed post-tag publication is
not atomic with tagging and requires the documented formula-only retry.
