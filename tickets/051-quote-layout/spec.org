* Synopsis
:PROPERTIES:
:CUSTOM_ID: summary
:END:
** Outcome
- Quotes use the *configured inset* and retain *normal paragraph separation*.
** Before
- Native quote padding adds *an unwanted inset*; block gaps replace separation.
** After
- Every quote paragraph starts at the *same configured left edge*.
- Quote clearance *adds to body paragraph separation*.
** Changes
- Quote spacing and indentation in =em= use the *body font size*.
** Unchanged
- Source syntax, quote typography, ordinary prose and code blocks *retain their contracts*.
** Edge cases
- Zero indentation means *no inset*. Multiple quote paragraphs add *no first-line indent*.
** Decisions
- Render quote *body content* within the existing configured wrapper.
** Next step
- Retain verification and review evidence for the *closure decision*.

* Acceptance Criteria
** AC051.1 - Quote inset equals configuration :ac:
:PROPERTIES:
:CUSTOM_ID: ac-051-1
:END:
- Criterion :: Every paragraph of a quote starts at *quote-block-indent from
  the body text edge*. Neither native quote padding nor prose first-line indent

- Proven by :: [[#rt-051-1][RT051.1 - Quote left-edge geometry]] and

** AC051.2 - Quote clearance adds to paragraph separation :ac:
:PROPERTIES:
:CUSTOM_ID: ac-051-2

- Criterion :: Space before and after a quote includes *normal body paragraph
  separation plus quoted-block-spacing*. Increasing that clearance adds the
  specified distance. An additional paragraph gap remains additive.
- Criterion :: Quote clearance in em uses the *body font size*. Quote font
  settings remain independent; ordinary prose and code spacing remain intact.
- Proven by :: [[#rt-051-2][RT051.2 - Quote boundary spacing]] and
  [[#ot-051-1][OT051.1 - Reported configuration probe]].

* Edge Cases
- Multiple quote paragraphs use *zero additional first-line indent* internally.
- Quote font size does not alter the configured body-based em inset or clearance.
- Existing native adjacent-block margin collapse remains unchanged.
- Objective rendered geometry covers this repair; no new subjective layout
  requirement or mandatory user test is introduced.

* Solution Design
** Quote rendering
- Keep the existing quote show rule and configured font role. In the body font
  context, set block sides to *par.spacing plus quoted-block-spacing*.
- Apply exactly the configured left padding, then the quote font. Render
  =it.body= rather than =it= to avoid applying native quote inset inside it.
- Set first-line indentation to zero inside the quote content only. Outer
  paragraph indentation and spacing remain in force outside that scope.
- No parser or loader changes are needed. Existing property assertions continue
  to check font values; PDF tests check actual spacing and complete inset.
** Security impact
- Existing escaping, validated configuration and content interpretation remain
  unchanged. No new dependency, trust boundary, access, network or source writes.
