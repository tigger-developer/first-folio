* Synopsis
:PROPERTIES:

** Outcome
- Script exports *omit references to defined footnotes* when footnotes are disabled.
** Before
- =render.footnotes: false= *drops definitions* but leaves their inline markers visible in PDF and DOCX.
** After
- *Defined references and their note text are hidden* in script outputs; adjacent text remains.
** Changes
- The shared script conversion filter *removes defined references* before output writers run.
** Unchanged
- *Enabled footnotes remain native*; manuscript and letter modes do not use this filter.
** Edge cases
- *Unresolved or escaped reference text remains literal*; repeated defined references are all hidden.
** Decisions
- The filter applies to the shared script event stream so output formats *agree*.
** Next step
- Retain internal reviews and hand the candidate back for the *operator closure decision*.

* Acceptance Criteria

** AC065.1 - Disabled script footnotes leave no defined reference text :ac:
:PROPERTIES:
:CUSTOM_ID: ac-065-1
:END:
- Criterion :: With =render.footnotes: false=, references to defined Org or Markdown script footnotes and their bodies *do not appear* in rendered script output. Text surrounding each reference *remains*, including when a note is referenced more than once.
- Boundary :: Unresolved or explicitly escaped reference syntax *remains literal*. With footnotes enabled, existing native notes and their references remain available.
- Proven by :: [[#rt-065-1][RT065.1 - Public script conversion suppresses defined references]] and [[#ot-065-1][OT065.1 - PDF and ODT output probe]].

* Edge Cases
- An escaped note marker is literal source text, so the filter *does not remove it*.
- A marker without a matching parsed definition *remains ordinary text*.
- Only script conversion is affected; other document modes *retain their own note semantics*.

* Solution Design

** Shared script event filter
- Collect defined note names before =applyScriptConfig= removes =EventFootnote= events. When footnotes are disabled, remove matching, unescaped Org/Markdown reference tokens from retained event text, names and directions. Preserve all other characters and the existing output writers.
- This filter is upstream of Typst/PDF, native DOCX and configured ODT writing. Text-format emitters also consume the filtered model. Enabled footnotes keep the previous path.

** Security and operational impact
- No new dependency, data source, external service or access is introduced. The filter operates on already parsed, bounded source strings. Existing output publication and error handling remain.
