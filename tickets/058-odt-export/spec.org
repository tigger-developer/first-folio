* Design
ODT projects the existing in-memory office layout into Pandoc JSON blocks and
styles. The current layout nodes are Word-shaped; this is a deliberate internal
bridge without generating or re-reading DOCX. Existing DOCX files are untouched.
A generated ODF reference supplies paragraph/text styles and page masters.
Pandoc writes the final ODT. There is no user-provided reference or arbitrary
Pandoc argument interface. A future neutral layout model is outside this change.
