* Context
:PROPERTIES:
:CUSTOM_ID: context
:END:

- Problem :: Script stage directions expose configurable space before but retain a hard-coded trailing gap.
- Scope :: Add =folio.positioning.stage-direction.space-after= to PDF, DOCX and ODT script conversion. Preserve =0.6em= when omitted. Text conversion, manuscripts and letters remain unchanged.
- Authority :: Operator emergency request on 2026-11-08; [[file:../../docs/config.md][configuration reference]] and [[file:../../docs/ARCHITECTURE.md][architecture]].

* Emergency Delivery Record
:PROPERTIES:
:CUSTOM_ID: emergency-delivery-record
:END:

- TDD :: The focused test first observed the hard-coded =0.6em= PDF value and =3.6pt= compacted office value instead of configured =0.75em= and =4.5pt= values.
- Actual change :: The shared script data carries an independent after length; Typst and native office styles consume it, with =0.6em= as the compatibility default.

* Solution Design
:PROPERTIES:
:CUSTOM_ID: solution-design
:END:

- Configuration :: Resolve =space-after= through the existing YAML cascade beside =space-before=.
- PDF :: Map it to Typst stage-direction block =below= spacing.
- DOCX and ODT :: Resolve it through the shared native direction paragraph style; ODT projects the DOCX-style semantics into ODF paragraph properties.
- Reliability :: Existing unit parsing, negative-spacing clamping, atomic conversion and format-specific compaction remain unchanged.
