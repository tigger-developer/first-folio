## Original issue body

## Problem

Many playwrights and theatre professionals are not comfortable with terminals, markup syntax, or YAML. First Folio's CLI is powerful but inaccessible to writers who just want to convert their script and generate a PDF.

## Vision

A simple companion app — not an editor, not an IDE — that wraps the CLI in an approachable interface. The writer opens their script file, clicks "Convert", and gets a PDF.

### Core features

- Open an org/Fountain/Markdown file
- Live-rendered preview (or preview on demand)
- "Convert to..." menu: PDF, Markdown, Fountain, org
- Style picker: British / American / Screenplay
- Letter generator: select recipients from :letter: sections, generate PDFs
- Drag-and-drop: drop a file onto the app to convert

### Design principles

- The app calls \`folio convert\` and \`folio letter\` under the hood — it is a GUI wrapper, not a reimplementation
- The source format remains plain text — the app is a window onto it
- No lock-in: everything the app does can be done from the terminal
- macOS-native (Swift/AppKit or SwiftUI) for first release

### Technology options

- **Swift + AppKit**: native macOS, can use Process to call folio CLI
- **Wails (Go + web)**: cross-platform, HTML/CSS/JS frontend — see ~/code/tigoss/hello-wails
- **Tauri (Rust + web)**: cross-platform, lightweight
- **Electron**: cross-platform but heavy

### Not in scope for v1

- Syntax highlighting or editing
- Real-time collaboration
- Cloud sync
- Mobile
