## Original issue body

## Problem

The current rendering engine uses hardcoded Typst templates and flat config values. British and American stage play layouts differ significantly in speaker alignment, dialogue placement, case conventions, and page geometry. The config system needs to drive the entire rendering pipeline, with a canonical British preset and an American override layer.

### Comment by tigger-developer at 2026-04-27T02:57:41Z

**AC3.8 (new):** Auto-capitalise character names in stage directions.

The character table provides a lookup list. At render time, character names appearing in stage direction text are uppercased (word boundary matching). Names in dialogue text are never modified — capitalisation in speech indicates shouting.

Rules:
- Stage directions (H3/action): character names → ALL CAPS
- Speaker label (H4): per config (small-caps or upper)
- Dialogue: never touch — writer's capitalisation is intentional

Implementation note: needs word-boundary-aware Unicode matching. Names like "Cáit" must match but "Cáitlín" must not. Partial name matches (e.g. "Bob" matching inside "Bobby") must be avoided.
