## Original issue body

# Problem

\`folio.manuscript.gutter\` is honoured on body pages but silently ignored on the title page and TOC page. Real-world impact: KDP (and other print-on-demand distributors that enforce a minimum inner/binding margin) reject manuscripts whose TOC violates the gutter requirement even when the body pages comply.

Root cause: \`templates/manuscript.typ\` emits a document-top \`#set page(margin: <flat scalar>, ...)\` (around line 200) that applies to the title page and TOC. Only the later body \`#set page(...)\` (around line 357) uses the parity-aware \`inside: margin + gutter, outside: margin, rest: margin\` idiom. Result:

- Title page: gutter absent
- TOC: gutter absent
- Body pages: gutter correct

# Reproduce

\`\`\`yaml
folio:
  manuscript:
    page: 5.5x8.5in
    margin: 20mm
    gutter: 15mm
    toc:
      enabled: true
\`\`\`

Render, then measure the inner (binding-side) margin on the TOC page and any body page. Body has \`20mm + 15mm = 35mm\` on the binding side. TOC has \`20mm\`. Difference visible; KDP flags it.

# Regression coverage

- RT-B1: Given \`gutter: 15mm\`, the document-top \`#set page(...)\` emits \`inside: 20mm + 15mm\`, \`outside: 20mm\`, \`rest: 20mm\` (parity-aware form), NOT a flat \`margin: 20mm\`.
- RT-B2: Given \`gutter: 0mm\` (default), the document-top \`#set page(...)\` emits the flat \`margin: 20mm\` form (backwards-compatible byte-for-byte output).
- RT-B3: Given \`gutter: 15mm\`, the TOC page's inherited margin is the parity-aware form (verified via the same emit-site check as RT-B1 -- the TOC's own \`#set page(numbering: none, footer: none)\` at line 317 only overrides numbering and footer, inheriting the margin).
- UT-B1: A reviewer confirms a rendered PDF with a non-zero gutter shows the same binding-side inset on the TOC and title page as on body pages.

# Solution design

Change the document-top \`#set page(...)\` at \`templates/manuscript.typ:200-204\` from:

\`\`\`typst
#set page(
  ...
  margin: {{.Config.Folio.Manuscript.Margin}},
  ...
)
\`\`\`

to the same parity-aware conditional used by the body \`#set page(...)\`:

\`\`\`typst
#set page(
  ...
  {{if .GutterActive}}margin: (inside: {{.Config.Folio.Manuscript.Margin}} + {{.Gutter}}, outside: {{.Config.Folio.Manuscript.Margin}}, rest: {{.Config.Folio.Manuscript.Margin}}),{{else}}margin: {{.Config.Folio.Manuscript.Margin}},{{end}}
  ...
)
\`\`\`

\`GutterActive\` and \`Gutter\` template fields already exist (issue #15 AC15.7 wired them; only the body page site used them until now).

Title page's own \`#set page(footer: [...])\` at line 213 does not need modification; it sets \`footer:\` only and inherits margin from the document-top call.

TOC's \`#set page(numbering: none, footer: none)\` at line 317 does not need modification; same reason.

# Backwards compatibility

- \`gutter: 0mm\` (default) leaves the emit byte-identical (flat \`margin: <M>\`).
- \`gutter: <non-zero>\` starts applying the correct inner margin to title and TOC pages, matching the body pages.
