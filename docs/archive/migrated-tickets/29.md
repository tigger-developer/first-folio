# Add total page count placeholder to manuscript headers and footers

## Feature

Manuscript header and footer formats support the current display page through `[page]`, but cannot include the document's final page count. Formats such as `[page]/[total-pages]` therefore cannot render `4/100`.

## Solution

Add `[total-pages]` to the manuscript header/footer placeholder grammar. The placeholder resolves through a Typst context helper to the final physical page counter, formatted as Arabic numerals. The total includes title, copyright, contents, body, and intentional blank pages and does not change when body display numbering resets.

Preserve existing placeholder substitution, separator filtering, unknown-token behaviour, and page-number formatting. Document the placeholder and its physical-page semantics in the configuration reference.

## Documentation

Add `[total-pages]` to the page-header/page-footer placeholder list with an example:

```yaml
folio:
  manuscript:
    page-footer:
      format: "[page]/[total-pages]"
```
