## Original issue body

## Requirement

Expose font letter spacing for manuscript body text, running headers, and running footers.

## Configuration Contract

```yaml
folio:
  manuscript:
    letter-spacing: 0em
    page-header:
      letter-spacing: 0em
    page-footer:
      letter-spacing: 0em
```

- The user-facing name is `letter-spacing`.
- Values are Typst lengths and map internally to Typst `text.tracking`.
- The manuscript default is `0em`.
- Header and footer inherit the manuscript value independently when omitted.
- Header and footer values override only their own text.
- Positive and negative values are supported.

## Regression Tests

- ✅ **RT-34.1:** Body, header, and footer default to `0em`.
- ✅ **RT-34.2:** An explicit manuscript value is inherited by an unset header and footer.
- ✅ **RT-34.3:** Header and footer overrides apply independently.
- ✅ **RT-34.4:** A header override does not alter an unset footer; the footer still inherits the manuscript value.
- ✅ **RT-34.5:** Typst compiles positive and negative `em` values in all three positions.
- ✅ **RT-34.6:** A rendered PDF shows increased text width for body, header, and footer tracking.

## User Test

- ✅ **UT-34.1 (PASS):** Inspect a generated manuscript with visibly distinct body, header, and footer letter spacing.
