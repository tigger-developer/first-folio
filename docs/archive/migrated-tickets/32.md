## Original issue body

## Context

Issue #27 removed clickable TOC annotations while correcting KDP non-printable output. The KDP-safe behaviour was made unconditional even though the product requirement had not changed. Chapter numbering also defaults to restarting per part despite continuous numbering being the expected manuscript default, and the current formatter cannot express part-qualified chapter numbers.

## Solution design

Add a typed TOC links field with an explicit default of true and conditionally wrap the existing custom outline-entry content in Typst `link(it.element.location(), ...)`. Preserve the custom entry layout so dot leaders, part bolding, and page numbers remain unchanged.

Change chapter reset normalization from `per-part` to `never`, retaining the existing post-parse continuous renumbering path and explicit `per-part` behaviour.

Parse chapter number-format with the grammar `[1Ii](\\.[1Ii])?`. A one-segment pattern formats the chapter counter. A two-segment pattern formats `current part counter + "." + chapter counter`. Keep counter scope orthogonal: `number-reset` controls whether the chapter counter is global or local. Validate formats rather than silently falling back to Arabic.

## Compatibility

- `toc.links: false` is the KDP-safe print-production override.
- Existing explicit `chapter.number-reset: per-part` retains its behaviour.
- Existing one-segment number formats retain their behaviour.
- Changing the reset and link defaults is intentional and must be documented in the changelog.
