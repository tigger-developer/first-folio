## Original issue body

# Problem

Two manuscript layout settings are parsed but do not satisfy their established contracts.

First, numeric `folio.manuscript.line-spacing` values are passed directly to Typst as `par.leading` lengths. Typst defines `leading` as the additional gap between adjacent line boxes, not as a line-height multiplier. Consequently, `1.0`, `1.5`, and `2.0` do not mean single, one-and-a-half, and double spacing. The implementation also substitutes line spacing for `paragraph-spacing: 0`, so zero paragraph spacing is not preserved.

Second, `folio.manuscript.page-header.content-padding-after` is emitted as one `v(...)` element before the complete manuscript body stream. It affects only the first body page and can displace a centred part divider, while prose on subsequent pages receives no configured header clearance.

This bug violates:

- AC9.8, especially RT-9.32: body/title content begins below the running header with configured top padding.
- AC9.13, especially RT-9.55 through RT-9.57: line spacing and paragraph spacing are independent configurable manuscript values.

# Regression coverage

- RT-9.32: Extend coverage through the public manuscript command so configured header padding changes the repeated prose-page body boundary, does not appear as a one-time flow spacer, and leaves the title page outside the running-header layout.
- RT-9.55: Strengthen British-default coverage so `1.5` represents a 1.5em baseline interval and `paragraph-spacing: 0` remains zero.
- RT-9.56: Strengthen US-default coverage so `2` represents a 2em baseline interval and `paragraph-spacing: 0` remains zero.
- RT-9.57: Strengthen explicit-override coverage for `1.0`, `1.5`, and `2.0`, non-zero paragraph spacing, and header padding through supported generated output.
- OT: Render PDF fixtures and measure line baselines and body starting positions across continuation pages; convert representative pages to PNG for layout inspection.

# Solution design

## Line spacing

Use Typst's documented font-independent baseline model:

- Set body text `top-edge: 0.8em` and `bottom-edge: -0.2em`, producing a one-em line box.
- Convert numeric spacing multiplier `m` to Typst leading `(m - 1)em`.
- Treat `paragraph-spacing` as additional space beyond the configured line interval. Configured zero therefore emits paragraph spacing equal to the computed leading, preserving the same baseline interval across paragraph boundaries; non-zero paragraph spacing is added to that leading.
- Reject or safely normalize values below `1.0` according to the existing lower-bound behaviour.

This yields:

- `1.0` -> `leading: 0em`, baseline interval 1em.
- `1.5` -> `leading: 0.5em`, baseline interval 1.5em.
- `2.0` -> `leading: 1em`, baseline interval 2em.

With `paragraph-spacing: 0`, the corresponding Typst paragraph spacing is `0em`, `0.5em`, or `1em`, so paragraph boundaries retain the selected baseline interval without adding an extra paragraph gap.

## Header-to-body padding

Remove the one-time vertical spacer before the body stream. Configure the repeated manuscript page run using Typst page geometry:

- Keep horizontal and bottom margins at `folio.manuscript.margin`.
- Establish the prose-page top body boundary from the running header's configured distance from the page edge plus `content-padding-after`.
- Set `header-ascent` so the running header occupies its configured edge position and the padding remains between the header and body boundary on every page.
- Keep the title page and table of contents under their existing page settings.
- Preserve physical centring of part-divider pages and configured chapter positioning while using the running header.

## Implementation constraints

- Keep the change in the Go manuscript renderer and file-backed Typst template.
- Use typed configuration values and template data; do not parse YAML or dimensions with regular expressions.
- Do not add one-off flow spacing or page-number conditionals to simulate repeated page layout.
- Propagate invalid configuration and Typst errors; do not suppress failures.
- Preserve British and US presets except where their existing numeric values acquire the correct documented semantics.

# Documentation impact

Update manuscript configuration documentation to state that numeric line spacing is a baseline multiplier, paragraph spacing is independent, and header content padding applies on every running-header page.
