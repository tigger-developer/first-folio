## Discovery

The manuscript renderer currently uses Markdown as the canonical render intermediate for issue #9 so that Markdown and org-mode manuscripts share one PDF layout path. A future architecture pass should evaluate making org-mode the canonical manuscript representation instead.

## Questions

- Whether org-mode should become the canonical internal manuscript contract for richer semantic extension.
- How Markdown should round-trip through an org-mode canonical model without losing supported v1 manuscript semantics.
- Which org-mode-only manuscript features should be accepted, rejected, or mapped into explicit AST fields.

## Notes
