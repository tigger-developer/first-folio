## Original issue body

## Problem

Script submissions require cover letters with specific structure. Writers send the same script to multiple theatres with minor personalisation. Currently cover letters are maintained separately from the script.

## Solution

A \`:letter:\` tag on H1 in an org file defines one or more cover letters. Each letter is rendered as a formatted PDF. Letters can be standalone or embedded in a script file.

### Org syntax

\`\`\`org
* Letters                                                    :letter:
** 15 Maple Avenue / Dublin                                  :sender:
** About Time — submission                                   :subject:
Dear [org],

Please find enclosed [title] ([version]) for your consideration.

*** Yours sincerely                                          :closing:
*** Taḋg Paul                                                :signoff:
*** Sarah O'Sullivan / Abbey Theatre / Dublin 1              :to:
**** The Abbey                                               :org:
*** Joe Bloggs / Gate Theatre / Dublin 1                     :to:
**** The Gate                                                :org:
\`\`\`

### Tag schema

| Level | Tag | Purpose |
|-------|-----|---------|
| H1 | \`:letter:\` | Marks the letter section |
| H2 | \`:sender:\` | Sender address (slash = line break) |
| H2 | \`:subject:\` | Subject line; body text follows as prose |
| H3 | \`:closing:\` | Sign-off text (default: "Yours sincerely") |
| H3 | \`:signoff:\` | Printed name (default: \`#+AUTHOR\`) |
| H3 | \`:to:\` | Recipient (slash = line break) |
| H4 | Any tag | Recipient-level variable for placeholder substitution |

### Placeholder substitution

Any \`[name]\` in the body is replaced from:
1. Recipient tags (H4 under \`:to:\`) — highest priority
2. Document front matter (\`#+KEY:\`) — fallback

Common placeholders: \`[org]\`, \`[moniker]\`, \`[title]\`, \`[subtitle]\`, \`[version]\`, \`[date]\`, \`[author]\`. Custom tags work with no code change.

### Defaults / inheritance

- **Date**: if not specified, use today's date (rendered as "1 May 2026")
- **Closing**: if not specified, default "Yours sincerely"
- **Signoff**: if not specified, fall back to \`#+AUTHOR\`
- **Sender**: if not specified, fall back to \`#+AUTHOR\`
- Multiple \`:to:\` under one \`:subject:\` = same letter to multiple recipients
- Multiple \`:subject:\` blocks = different letters

### Output

- \`folio cover script.org\` → generates one PDF per recipient
- \`folio cover script.org --to Abbey\` → generates for specific recipient
- Output files named \`cover-{org-slug}.pdf\`
