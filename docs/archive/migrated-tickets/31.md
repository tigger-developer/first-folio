## Original issue body

## Requirement

A multi-page manuscript table of contents needs configurable top padding on continuation pages so its first entry aligns vertically with the first entry beneath the heading on page one.

## Acceptance criteria

| ID | Acceptance criterion | Tests |
|---|---|---|
| AC31.1 | `folio.manuscript.toc.continuation-padding-before` accepts a Typst length and reserves that height above TOC entries on every TOC page. The Contents heading occupies the reserved band on page one, while continuation pages leave it blank, so entry lists share a vertical start. The British base default is `15mm` and is inherited by US manuscripts. | ⏳ RT-31.1: a public PDF render confirms first-entry coordinates align across two default TOC pages<br>⏳ RT-31.2: generated output uses the `15mm` base default when the key is absent<br>⏳ RT-31.3: a `20mm` override moves both pages’ entry starts by approximately `5mm` while retaining alignment<br>⏳ UT-31.1: human checks the default two-page TOC alignment |

## Solution design

Increase the TOC page top margin by `continuation-padding-before` on every TOC page. Remove the Contents heading from normal flow and place it in the reserved band on page one. Typst then paginates every TOC page through the same body-start coordinate without detecting automatic page transitions or manually counting entries.

## Scope

This changes only manuscript TOC layout. It does not alter body-page margins, TOC entry line spacing, or page numbering.

## Recommended design amendment

Avoid continuation-page detection. Increase the TOC section top margin by `continuation-padding-before` on every TOC page, then place the Contents heading into that reserved area on page one. Entries on page one and continuation pages consequently share the same body-start coordinate. This reflows content through Typst page layout and needs no manual entry counting.

This changes the draft AC/test wording: configured padding deliberately establishes the common entry start on every TOC page rather than preserving page one’s prior coordinate.
