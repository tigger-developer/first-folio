## Original issue body

## Problem

Within-scene elements (stage directions, prop text, transitions) previously used a mix of heading levels (H3, H5) and ad-hoc syntax (\`- *"TEXT"*\`). This was inconsistent and didn't fold well in Emacs org-mode.

## Solution

All within-scene elements use H3 headings, differentiated by org tags. Untagged H3 defaults to stage direction (the most common element).

### Tag schema

| Tag | Event | Example |
|-----|-------|---------|
| (none) | stage_direction | \`*** A bare stage.\` |
| \`:prop:\` | prop_text | \`*** BREAKFAST :prop:\` |
| \`:transition:\` | transition | \`*** Lights down :transition:\` |

### Heading level summary

| Level | Meaning |
|-------|---------|
| H1 \`*\` | Act / intro section / characters / letters |
| H2 \`**\` | Scene |
| H3 \`***\` | Within-scene element (tag determines type) |
| H4 \`****\` | Character + dialogue |

### Guidance for related cues

These do not need their own tags — use the existing schema:

| Cue type | Recommendation | Example |
|----------|----------------|---------|
| Lighting | Use \`:transition:\` — lighting changes are scene transitions | \`*** Lights fade to blue :transition:\` |
| Sound/SFX | Write inline in stage direction, capitalise per convention | \`*** A GUNSHOT echoes across the hall.\` |
| Music (song reference) | Use \`:prop:\` — a named song is on-stage content | \`*** Yesterday by The Beatles :prop:\` |
| Music (lyrics/singing) | Use character dialogue — it's performed speech | \`**** Sarah\` then the lyrics as dialogue |
| Director notes | Write as stage direction (untagged H3) | \`*** Beat.\` |

### Backward compatibility

- H5 transitions continue to work (deprecated)
- \`- *"TEXT"*\` prop text continues to work (deprecated)
