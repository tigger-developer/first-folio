# Iosevka Publish

These are the operator's customized Iosevka Publish fonts, copied unchanged
from `~/Library/Fonts/IosevkaPublish-*.ttf` on 12 October 2026. They were not
downloaded or rebuilt. Font metadata reports version 34.8.1 and copyright
2015-2026 Renzhi Li. The operator confirms the standard Iosevka open source
licence applies to this customized family.

The accompanying unmodified SIL Open Font Licence 1.1 notice was obtained
from the matching upstream version:
<https://raw.githubusercontent.com/be5invis/Iosevka/v34.8.1/LICENSE.md>.
This URL identifies the notice, not the source of these customized binaries.
The font licence is separate from First Folio's MIT licence.

Typst identifies two families: `Iosevka Publish` and
`Iosevka Publish Extended`. Each has regular, italic, bold and bold italic
faces. The extended family's native width is 125%.

All eight faces and this notice are embedded in the executable. Font
files are extracted temporarily for PDF compilation and included as complete
faces in DOCX and ODT exports when their family is referenced. No font installation, font download
or font build occurs during a First Folio build or conversion.
