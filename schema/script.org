* Schema Declaration
:PROPERTIES:
:CUSTOM_ID: schema-declaration
:END:
Stage plays and screenplays use this schema. Every Org script example and every conversion to this format must include the full schema URL in frontmatter:

#+begin_src org
,#+SCHEMA: https://github.com/tigger-developer/first-folio/blob/master/schema/script.org
#+end_src

Conversion must select the schema for the *destination format and document type*, including when the source has no schema field. The schema URL identifies the document structure; it is not body text or a typography preset.

*Reference example:* [[file:../examples/play-example.org][play-example.org]].

*Implementation status:* This document defines the requested schema contract. Automatic schema emission is pending the converter changes tracked by [[file:../docs/work.org::#w-041][W041 - Document schemas and schema frontmatter]]. Existing converter metadata behaviour is described below; it does not yet implement this declaration.

* Scripts and Letters
:PROPERTIES:
:CUSTOM_ID: scripts-and-letters
:END:
An Org script can contain both the play and cover letters. Letter sections follow the [[file:letter.org][Org Letter Schema]]. The combined Org document declares the script schema; the =:letter:= subtree supplies the letter structure.

Play conversion must ignore each =:letter:= section and its descendants, including when writing Org, Markdown, Fountain, Typst, or PDF. The =folio letter= subcommand generates only recipient letters from those sections, using shared document metadata where required; it does not generate the play.

*Implementation status:* Exclusion during play conversion is required here and tracked by [[file:../docs/work.org::#w-040][W040 - Exclude cover-letter sections from document rendering]]; it has not yet been corrected in the converter.

*Combined example:* [[file:../examples/about-time.org][about-time.org]]. *Screenplay example:* [[file:../examples/cold-open.org][cold-open.org]].

* Existing Format Contract
:PROPERTIES:
:CUSTOM_ID: existing-format-contract
:END:
Org-mode is the primary authoring format for First Folio. It uses Emacs org-mode heading levels to encode the hierarchical structure of a stage play. The element definitions below describe the supported play structure and conversion limits.

*External reference:* [[https://orgmode.org/manual/Document-Structure.html][orgmode.org - Document Structure]]

*Intro sections:* H1 headings before the first character dialogue (e.g. Synopsis, Setting, Scene List) are automatically detected as intro material. These render the same as act headers but can be toggled with =render.frontmatter= in [[file:../docs/config.md][config]].

* Element Schema
:PROPERTIES:
:CUSTOM_ID: element-schema
:END:
** Front Matter
:PROPERTIES:
:CUSTOM_ID: front-matter
:END:
Org-mode keyword lines at the top of the file. Any =#+KEY: value= line is captured by the parser. Org emission preserves =TITLE=, =SUBTITLE=, =AUTHOR=, =DATE=, and =VERSION=; arbitrary keys are not guaranteed to survive a text-format round trip.

#+begin_src org
,#+SCHEMA: https://github.com/tigger-developer/first-folio/blob/master/schema/script.org
,#+TITLE: The Importance of Being Earnest
,#+AUTHOR: Oscar Wilde
,#+SUBTITLE: A Trivial Comedy for Serious People
,#+TEMPLATE: play
#+end_src

Standard emitted keys are =TITLE=, =SUBTITLE=, =AUTHOR=, =DATE=, and =VERSION=.

** Acts (H1)
:PROPERTIES:
:CUSTOM_ID: acts-h1
:END:
Level-1 headings represent acts. The heading text becomes the act title.

#+begin_src org
,* Act I
,* Act II
,* Epilogue
#+end_src

The special heading =* CHARACTERS= (case-insensitive, singular or plural) is not an act - it introduces a character table (see below).

** Scenes (H2)
:PROPERTIES:
:CUSTOM_ID: scenes-h2
:END:
Level-2 headings represent scenes within an act.

#+begin_src org
,** Scene 1
,** Scene 2 — The Garden
#+end_src

** Stage Directions (H3)
:PROPERTIES:
:CUSTOM_ID: stage-directions-h3
:END:
Level-3 headings represent stage directions (also called action text or narrative). These describe setting, movement, and physical action.

#+begin_src org
,*** A morning room in Algernon's flat in Half-Moon Street.
,*** JACK enters through the French windows.
#+end_src

Org-mode inline markup is retained in event text and interpreted by the Org-aware PDF renderer. Text-format emitters do not translate every inline marker between Org, Markdown, and Fountain, so inline emphasis is not guaranteed to retain identical semantics across a text-format round trip.

** Characters (H4)
:PROPERTIES:
:CUSTOM_ID: characters-h4
:END:
Level-4 headings introduce a character who is about to speak. The heading contains the character name in ALL CAPS, optionally followed by a parenthetical direction.

#+begin_src org
,**** ALGERNON
,**** JACK earnestly
,**** LADY BRACKNELL (rising)
,**** GWENDOLEN, with great feeling
#+end_src

All of the following direction formats are normalized to the same internal representation:

| Syntax               | Name | Direction |
|----------------------+------+-----------|
| =**** BOB softly=    | BOB  | softly    |
| =**** BOB (softly)=  | BOB  | softly    |
| =**** BOB, softly=   | BOB  | softly    |
| =**** BOB, (softly)= | BOB  | softly    |
| =**** BOB=           | BOB  | (none)    |

Character names support Unicode: =CÁIT=, =MAIRÉAD=, =SÉAN=.

** Dialogue
:PROPERTIES:
:CUSTOM_ID: dialogue
:END:
Plain text following an H4 heading. Multiple lines are preserved. Blank lines are consumed silently.

#+begin_src org
,**** ALGERNON
I don't think there is much likelihood, Jack,
of you and Miss Fairfax being united.
#+end_src

The same inline-markup limitation applies to dialogue: PDF rendering understands the Org source markers, while text-format emission preserves the event text rather than normalizing all target markers.

** Character Table
:PROPERTIES:
:CUSTOM_ID: character-table
:END:
A level-1 heading =* CHARACTERS= (or =* CHARACTER=) followed by an org table listing the cast.

#+begin_src org
,* CHARACTERS
|----------+------------------------------|
| ALGERNON | A young man about town       |
| JACK     | His friend, also young       |
| LANE     | Algernon's manservant        |
|----------+------------------------------|
#+end_src

Separator rows (=|---+---|=) are ignored. Each data row emits a =character_table_row= event with the name and description.

** Prop Text
:PROPERTIES:
:CUSTOM_ID: prop-text
:END:
On-stage text (signs, letters, placards) uses a level-3 heading tagged =:prop:=. The parser also accepts the historical list-item form.

#+begin_src org
,*** WELCOME TO THE GARDEN PARTY                              :prop:

- *"WELCOME TO THE GARDEN PARTY"*
#+end_src

Both forms emit the same =prop_text= event. First Folio emits the tagged-heading form when writing Org.

** Transitions
:PROPERTIES:
:CUSTOM_ID: transitions
:END:
A transition uses a level-3 heading tagged =:transition:=. The parser also accepts a level-5 heading as a compatibility form.

#+begin_src org
,*** BLACKOUT                                                :transition:
#+end_src

** Footnotes
:PROPERTIES:
:CUSTOM_ID: footnotes
:END:
Org-mode footnote definitions. The reference =[fn:name]= appears inline in dialogue or directions; the definition appears on its own line.

#+begin_src org
[fn:verse] From Tennyson's "In Memoriam", Canto 27.
#+end_src

** Noexport Sections
:PROPERTIES:
:CUSTOM_ID: noexport-sections
:END:
Any heading tagged =:noexport:= is excluded from output, along with all its children.

#+begin_src org
,*** Notes on staging :noexport:
These are private notes and will not appear in any output.
#+end_src

* Complete Example
:PROPERTIES:
:CUSTOM_ID: complete-example
:END:
#+begin_src org
,#+SCHEMA: https://github.com/tigger-developer/first-folio/blob/master/schema/script.org
,#+TITLE: A Short Play
,#+AUTHOR: A. Playwright

,* CHARACTERS
|------+------------------|
| BOB  | An ordinary man  |
| CÁIT | His neighbour    |
|------+------------------|

,* Act I
,** Scene 1
,*** A kitchen. Morning. Sunlight through the window.
,**** BOB
Good morning.

,*** BOB crosses to the kettle.

,**** CÁIT (entering)
Is the kettle on?

,**** BOB cheerfully
Just boiled.

,*** Research notes :noexport:
- Look up kettle brands for period accuracy.
#+end_src
