* Scope

This schema describes *prose manuscript source*, separate from the script
format. =folio manuscript= accepts Org manuscripts and renders Typst or PDF.
It interprets Org through First Folio's manuscript model and does not expose
an Org manuscript output command.

- Reference example :: [[file:../examples/dummy-manuscript.org][The Glass Orchard]].
- Equivalent source contract :: [[file:manuscript.md][Markdown manuscript schema]].

* Frontmatter

Place document keywords at column one before the body:

#+begin_src org
#+SCHEMA: https://github.com/tigger-developer/first-folio/blob/master/schema/manuscript.org
#+TITLE: The Glass Orchard
#+SUBTITLE: A Novel
#+AUTHOR: Example Author
#+ATTRIBUTION: by
#+DATE: 2026-09-10
#+VERSION: Draft 1
#+WORDCOUNT: about 90,000 words
#+CONTACT-NAME: Example Agent
#+ADDRESS: 100 Example Street / Sample City
#+PHONE: +353 1 000 0000
#+EMAIL: author@example.invalid
#+WEBSITE: https://example.invalid
#+end_src

- =SCHEMA= :: Identifies manuscript structure rather than play structure.
- =TITLE=, =SUBTITLE=, =AUTHOR= :: Manuscript identification.
- =ATTRIBUTION= :: Optional prefix before the author name; empty by default.
  The format reference also specifies =AUTHOR-ATTRIBUTION= as an alias.
- =DATE=, =VERSION= :: Manuscript date and draft label.
- =WORDCOUNT= :: Display text, not a computed count. Values such as
  =about 90,000 words= and =90000= are retained as entered.
- =CONTACT-NAME=, =ADDRESS=, =PHONE=, =EMAIL=, =WEBSITE= :: Optional contact
  details. Contact name does not fall back to the author name.

Write dates as ISO dates. Their rendered appearance, and the inclusion of
contact details, are controlled by manuscript configuration.

Known implementation gap: the format reference specifies the Org attribution
keywords above, but the current Org metadata parser does not retain them.
They are documented contract fields, not verified current source overrides.

* Document structure

| Source form | Manuscript meaning |
|-------------+--------------------|
| =* PART ONE= | Part division |
| =** Chapter 1= | Chapter |
| =*** Section= and deeper headings | Local section |
| Plain paragraphs separated by blank lines | Prose |
| =-----= or =_____= alone on a line | Scene break |

Part and chapter headings are prose divisions, not acts and scenes. Chapter
and part numbering and page layout are controlled by manuscript configuration.
Scene breaks render using the configured marker, which defaults to a centred
=#=.

Only a prose paragraph immediately opening a chapter is flush left. Other
paragraphs use the configured indentation, including prose after a structural
block at the start of a chapter.

* Inline text and supporting blocks

| Source form | Meaning |
|-------------+---------|
| =*bold*= | Bold |
| =/italic/= | Italic |
| =+deleted+= | Strikethrough |
| ~=code=~ | Monospace text |
| =--= and =---= within text | En dash and em dash |
| =[fn:note]= | Footnote reference |
| =[fn:note] Explanation.= on its own line | Footnote definition |

A verbatim span within prose stays inline. A verbatim span occupying an entire
line follows the manuscript code-block layout.

The supported supporting blocks are Org quote blocks, source blocks, links,
lists, and tables, as illustrated by the linked example. Their typography and
spacing belong to [[file:../docs/config.md][manuscript configuration]].

A heading tagged =:noexport:= excludes that heading and its descendants until
the next heading of the same or a higher level.

* Boundaries

Source-document images and Fountain input are outside the manuscript contract.
The presence of a schema URL does not add an output format. This declaration
is required for Org manuscript examples and for any Org manuscript output;
there is currently no writer for the latter.

The existing Markdown manuscript serializer uses the Markdown manuscript URL.
Typst and PDF output do not receive a schema declaration.
