* Scope

Letters are an *Org-only* document type. =folio letter= reads tagged Org
sections and generates recipient-specific PDFs. There is *no Markdown letter
format* and no Markdown letter conversion.

An Org file may contain both a play and cover letters. It declares the
[[file:script.org][Org script schema]], while its =:letter:= subtrees follow this
letter schema. =folio letter= uses those subtrees and shared document metadata;
it does not generate the play.

- Reference example :: [[file:../examples/about-time.org][About Time, with play and letter sections]].

A letter-only Org source declares:

#+begin_src org
#+SCHEMA: https://github.com/tigger-developer/first-folio/blob/master/schema/letter.org
#+AUTHOR: A. Playwright
#+TITLE: A Short Play
#+end_src

The PDF output does not receive a schema declaration.

* Section grammar

| Heading form | Meaning |
|--------------+---------|
| =* Cover letters :letter:= | Start of a letter section |
| =** A. Playwright / Dublin :sender:= | Sender address |
| =** Submission of A Short Play :subject:= | New subject and letter body |
| Plain paragraphs following the subject | Body text |
| =*** Yours sincerely :closing:= | Closing |
| =*** A. Playwright :signoff:= | Signature text |
| =*** Editor / Example Theatre / Dublin :to:= | Recipient address |
| =**** Example Theatre :org:= | Recipient organization |
| =**** Alex :moniker:= | Recipient salutation value |
| =*** [2026-09-10 Thu]= | Letter date |

The next level-one heading without =:letter:= ends the section. A subject
requires at least one recipient to produce a letter. Several =:to:= headings
produce separate letters from the same body. Several =:subject:= headings
allow different letter bodies in one section.

Sender information applies to subsequent subjects until another sender is
specified. Missing sender and sign-off values fall back to =#+AUTHOR:=;
a missing closing defaults to =Yours sincerely=.

* Metadata and body substitutions

Shared document keywords supply values such as =title=, =subtitle=, =author=,
=date=, and =version=. =EMAIL= and =CONTACT= can supply sender contact details.

A body placeholder uses square brackets, for example =[title]= or =[org]=.
A recipient's level-four tagged heading defines a value using the tag name:
=**** Friday :deadline:= supplies =[deadline]=. Names use letters, digits,
or underscores.

- Recipient values override matching document values.
- Unknown placeholders remain unchanged.
- Substitution applies to the body, not the subject, closing, or sign-off.

* Command boundary

- =folio letter source.org= :: Generate the recipient letters only.
- =--to RECIPIENT= :: Select matching recipients using a regular-expression
  substring match.
- =--dir DIRECTORY= :: Choose the PDF output directory.
- =--prefix PREFIX= :: Choose the filename prefix.

Play conversion must ignore =:letter:= subtrees when processing a combined
Org document. That exclusion is an outstanding implementation defect tracked
by [[file:../docs/work.org::#w-040][W040 - Exclude cover-letter sections from document rendering]].
It does not make letters part of any other source format.
