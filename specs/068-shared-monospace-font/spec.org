:PROPERTIES:

** Outcome
- Every applicable command uses *one top-level monospace font definition*.
** Before
- Manuscripts expose =folio.manuscript.mono.font=, while script conversion has *no corresponding configurable monospace role*.
** After
- =folio.mono.font= configures monospaced inline and block content across the application.
- Existing =folio.manuscript.mono.font= input remains effective as a compatibility input for the shared role and emits a migration warning.
** Changes
- Move the public monospace font authority to the top-level =folio= object and project it into format-specific renderers.
** Unchanged
- Existing configuration precedence, non-monospace font roles, document parsing and output selection remain unchanged.
** Edge cases
- When both paths are present, the top-level path wins at the same configuration layer; higher-precedence layers continue to win normally.
** Decisions
- The legacy manuscript path is deprecated, not removed.
** Next step
- Audit and obtain operator sign-off before delivery.

* Context

** Authority and baseline
- Authority :: On 2026-10-23 the operator requested an application-level monospace definition modelled on the shared page-header and page-footer migration.
- Baseline :: =folio.manuscript.mono.font= configures manuscript inline and block code. Script conversion has no public monospace font role.
- Scope :: Configuration loading, validation, warnings, documentation and applicable PDF, Typst, DOCX and ODT renderers for manuscript, script conversion and letters.
- Exclusions :: Changing source syntax, converting ordinary text to monospace, removing the legacy path or changing unrelated typography defaults.

* Solution Design

** Configuration normalization
- Add =folio.mono.font= to the shared font-role schema with the full font attribute contract.
- Normalize each loaded layer before recursive merge, following the established shared running-matter pattern. Project legacy manuscript values into the shared role first, then let explicit shared values in the same layer override them.
- Retain the manuscript renderer's typed field as an internal compatibility projection until the deprecated public path is retired.

** Diagnostics
- Detect only user-supplied legacy paths and collect one migration warning per supplied layer using the existing configuration warning channel.
- Public commands write collected warnings to stderr without changing successful output or stdout.

** Renderer integration
- Route monospaced inline and block content through the shared effective font in each applicable renderer.
- Preserve the output-specific implementation of each attribute. In PDF and Typst paths, stretch uses the application geometric-scaling contract rather than Typst width-face selection.

** Security and operational impact
- No new dependency, service, persistence or input surface is introduced. Existing validation and bounded rendering rules apply to the shared values.
