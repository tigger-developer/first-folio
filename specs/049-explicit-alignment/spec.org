* Synopsis
:PROPERTIES:
:CUSTOM_ID: summary
:END:
** Outcome
- Configuration supplies *explicit alignment choices* and rejects invalid values.
** Before
- Empty title-page alignments selected *hidden grouping*; other invalid values
  could fall back silently or reach the renderer.
** After
- Six title-page items use *=group=*; invalid resolved alignments *fail before output*.
** Changes
- Shared validation covers *all shipped alignment fields*.
- US date/version omission is *explicit*; enabling either produces its content.
** Unchanged
- *Optional empty content*, preset precedence and default title-page placement remain.
- Unrelated British preset edits remain *outside this change*.
** Edge cases
- Null, non-string, empty and unknown alignment values *fail*, even for disabled roles.
- Omitted overrides *inherit*; =group= is valid only for six title-page items.
** Decisions
- Group is an *explicit layout choice*, preserving established grouped spacing.
** Next step
- Retain verification, review the reconciled definition and obtain *closure*.

* Edge Cases
- *Explicit null does not mean inherit* for alignment. Omitting an override does.
- *Invalid inactive roles fail* at the common boundary, matching font validation.
- *=group= is not a compass value*: contact, group alignment controls and running
  matter reject it. Each retains its documented vocabulary.
- Unrecognized fields outside the shipped alignment inventory remain outside
  this change; the shared loader's general unknown-key policy is unchanged.

* Solution Design
** Configuration and rendering
- The shared loader validates a *finite inventory of paths and vocabularies*
  after merging and before typed decode or output. No renderer can turn a
  resolved empty alignment into a default.
- Trim surrounding whitespace. Preserve case-insensitive part vertical aliases;
  other alignment keywords remain case-sensitive.
- The six title-item =group= values map to the existing group branch in the
  manuscript template. Other accepted values produce independent placement.
- British footer remains in the page footer. US uses a bottom-placed three-column
  row; date/version flags default to false. The title group retains its existing
  order and gaps. Configuration defines group participation and group alignment;
  templates retain ownership of composition.
- No dependencies, schema framework or new group-order/gap controls are needed.
- Structural review :: Confirm validation occurs after all shared layers, before
  output, and that no unrelated preset edits enter the change.
** Security impact
- The existing YAML-to-Typst *trust boundary is strengthened* with allowlists.
  Expression-like alignment input fails before interpolation. No access,
  network, secret handling or durable data changes are introduced.
