* Emergency reconciliation - 2026-10-12
The operator authorized BYPASS-GATE-7 and required the installed customized
fonts to be copied without download or build. The earlier instruction to use
self-review instead of the broken external audit harness remains applicable.
This record is retrospective reconciliation, not an advance definition verdict.

** Actual implementation
All eight local font binaries and their standard OFL notice are embedded.
Their hashes match the installed originals; metadata identifies regular and
extended families at version 34.8.1. The shared compile helper preserves
caller font paths and cleans its private extraction directory on failure too.
The US YAML supplies every script font role and centred speaker alignment.
Removing the obsolete US manuscript mono family lets it inherit Iosevka Publish
from the British base, retaining its configured bold weight.

A generic template correction was also required: separate-line dialogue blocks
now have width 100%, allowing configured alignment to use the available width.
A temporary-source probe moved the cue centre from 82.87 pt to 297.64 pt on an
A4 page while leaving dialogue at 70.87 pt. No US-specific branch was added.
The same template serves screenplay; its configured alignments also benefit.
British same-line dialogue and office writer implementations are unchanged.

** Cause and test gap
Commit 47aa1d4 (1 May 2026) moved the Courier Prime / centred-cue preset to the
screenplay style and made the US stage-play preset serif with left cues.
Later preset migration retained those values. Existing parity tests asserted
that layout was emitted and styles differed, without requiring the correct
PDF font or cue coordinates. The new regression inspects both actual outputs.
Separately, the current separate-line template's automatic block width defeated
centring even after the YAML was corrected. Git blame dates that block line
to c4fcc722 (13 July); this observation does not establish when every historical
Typst version first manifested the behaviour.
